## Files added

| File | What it does |
|---|---|
| `vercel.json` | 18 × 301 redirects for the retired Wix URLs, plus cache headers and basic security headers |

| `sitemap.xml` | One entry today; add a `<url>` block per page as service/location pages ship |

| `fonts/manrope-latin.woff2`<br>`fonts/manrope-latin-ext.woff2` | The font files. 40 KB total (Manrope is variable — one file covers weights 500–800) |

## Files changed

**`index.html`**

- Google Fonts request removed → self-hosted, with a `preload` on the latin file
- Leaflet CSS switched to non-blocking (`media="print"` + `onload`), with a `<noscript>` fallback. Leaflet's JS was already bottom-of-body and is untouched — the map still initialises exactly as before
- Hero image now `preload`ed with `fetchpriority="high"` — this is the LCP win
- All five images: WebP `src` + `srcset` + `sizes` + explicit `width`/`height`; below-fold images `loading="lazy"`
- Reviews section given a real `<h2>` (screen-reader-only, so **no visual change**)
- Footer headings promoted `<h4>` → `<h3>` so heading order is sequential
- Commented-out blocks ready for the Search Console token and the GA4 Measurement ID

**`css/styles.css`**

- `--whatsapp` darkened `#25d366` → `#0f7a6c`. White text on the old green was 1.98:1, a WCAG failure. Now 5.2:1, passes AA. Still reads as WhatsApp green
- `.site-footer h3` added alongside the existing `h4` rule so the promoted headings look identical
- `.sr-only` utility added for the reviews heading

## Not touched

- No copy changes, no layout changes, no pricing logic, no form logic
- Original JPEGs and `logo.png` left in place — `logo.png` is still the favicon and `van.jpg` is still the `og:image`. Neither is downloaded by visitors any more
- `assets/fitting.jpg` and `assets/tyretread.jpg` are referenced nowhere. Safe to delete whenever you like; they cost visitors nothing

## Deploy

From `Website Build/`:

```bash
rm -f .git/index.lock          # only if git complains about a stale lock
git add -A
git commit -m "Technical SEO: 301 redirects, robots+sitemap, WebP images, self-hosted font, a11y fixes"
git push
```

Vercel auto-deploys from `main`.

### Straight after it goes live

1. **Check the redirects.** `curl -sI https://www.resqtyres.co.uk/contact-us` should return `301`, not `404`.
2. **Search Console.** Add the property, take the HTML-tag token, paste into the commented `<meta>` in `<head>`, uncomment, push. Then submit `https://www.resqtyres.co.uk/sitemap.xml`.
3. **GA4.** Create the property, drop the Measurement ID into the commented block, uncomment, push. The click handler already tracks `call_click` and `whatsapp_click` — for a phone-driven trade those are the only conversions that matter.
4. **Re-run PageSpeed** on the live URL and save the number as the baseline.
